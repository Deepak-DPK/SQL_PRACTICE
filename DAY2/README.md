# DAY2 SQL Practice

This folder contains SQL query exercises focused on filtering, deduplication, grouping, and basic aggregates.

## Files

- `ns_unique_cities.sql` — List distinct patient cities for province `NS`.
- `patient_579_admissions.sql` — Count total admissions for patient `579`.
- `same_day_admissions.sql` — Find admissions where admission and discharge are on the same date.
- `tall_heavy_patients.sql` — Show patients with `height > 160` and `weight > 70`.
- `total_admissions.sql` — Return total number of admissions.
- `unique_birth_years.sql` — List unique patient birth years in ascending order.

## Notes

- Tables used: `patients`, `admissions`
- SQL concepts covered: `DISTINCT`, `WHERE`, `COUNT`, `GROUP BY`, date filtering, ordering.
